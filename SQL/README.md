# SQL Analysis Documentation

This folder contains the SQL work used for the Supply Chain Performance & Operations Analytics project.

## Files

| File | Purpose |
|---|---|
| `00_Original_SQL_Workbench.sql` | Corrected original SQL Workbench script, preserved as the source version. |
| `01_Database_Setup.sql` | Database setup, table inspection, row counts, and initial structure checks. |
| `02_Data_Quality_Validation.sql` | Missing-value, uniqueness, duplicate, range, date, and referential validation checks. |
| `03_Inventory_Backorder_Analysis.sql` | Consumption, inventory, backorders, inventory coverage, and part-level risk analysis. |
| `04_Supplier_Performance_Analysis.sql` | Supplier delivery performance, late orders, quality linkage, and supplier-part risk analysis. |
| `05_Forecast_Analysis.sql` | Forecast accuracy, forecast bias, and Mean Absolute Error (MAE). |
| `06_Site_Operations_Analysis.sql` | Site-level operations, inventory, backorders, maintenance, blocked inventory, and time-based analysis. |
| `07_Quality_Incident_Analysis.sql` | Quality incidents, defect types, severity, scrap, supplier, and site-level analysis. |

## Approach

The SQL workflow was used to inspect the datasets, validate data quality, perform operational analysis, calculate business metrics, and generate analytical outputs that supported the Power BI dashboard.

The original Workbench script is retained separately so the complete source work remains available.
